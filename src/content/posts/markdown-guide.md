Markdown 的好处是：用最少的心智负担，把结构表达清楚。下面是我自己写文章时会用到的部分。

## 标题与段落

```markdown
# 一级标题
## 二级标题
### 三级标题
```

段落之间空一行即可。

## 强调

```markdown
**加粗**、*斜体*、~~删除线~~、`行内代码`
```

效果：**加粗**、*斜体*、~~删除线~~、`行内代码`。

## 列表

无序列表用 `-`，有序列表用 `1.`，可以嵌套：

```markdown
- 第一层
  - 第二层
- 另一种是
  1. 有序的
  2. 嵌套
```

## 链接与图片

```markdown
[链接文字](https://example.com)
![图片描述](/favicon/logo.jpg)
```

## 引用

```markdown
> 这是一段引用。
> 可以有多行。
```

## 表格

```markdown
| 语法 | 效果 |
| --- | --- |
| `**粗**` | **粗** |
| `*斜*` | *斜* |
```

| 语法 | 效果 |
| --- | --- |
| `**粗**` | **粗** |
| `*斜*` | *斜* |

## 任务列表

```markdown
- [x] 已经做完的事
- [ ] 还没做的事
```

- [x] 已经做完的事
- [ ] 还没做的事

## 脚注

正文里写 `这是一句话[^1]`，文末写 `[^1]: 脚注内容`，会得到一个可点击的角标。[^1]

## 几条经验

1. **一段只说一件事**，段落短一点更像在说话
2. 标题层级不要跳（`#` 之后直接 `###` 会让结构变乱）
3. 代码块一定标语言，高亮才有意义
4. 少用加粗，用多了就没重点了

[^1]: 就像这样，脚注内容会出现在文末。
